# 素材整理器

macOS 菜单栏小工具：自动把散落的视频、图片、产品文件、网页和 SEO/GEO 文件整理到桌面的固定目录，每次移动都能撤销。

> 自用工具，只在作者的 Mac（Apple M4、macOS 26.4）上测过，不保证其他环境可用。

## 整理到哪里

```text
社媒/视频/视频发布/     已发布的视频
社媒/视频/视频待发布/   未发布的成片
社媒/图片/图片成品/     AI 图、设计导出
产品/<项目>/            最新版本；旧版本进「历史版本/」
网站相关/网站维护/      html / css / js
网站相关/SEO GEO/       sitemap、llms.txt、schema 等
待删/                   缓存、日志、渲染帧（只归档，不删除）
其他/                   拿不准的文件
```

路径都能在设置里改。

## 怎么用

1. 打开 `素材整理器.app`。它在菜单栏里，Dock 里没有图标。
2. 按引导选素材库（默认桌面）和要扫描的文件夹。
3. 在「待整理」里核对每个文件要去哪、为什么。
4. 第一次确认只是演练，第二次才真正移动。
5. 不满意就按 ⌘Z，或在「记录」里撤销。

⌥⌘O 可以随时搜索已归档的文件。

## 安全

- 不删除、不覆盖任何文件，重名时会自动加日期。
- 不碰系统目录、`~/Library`、`.app`、`.git`。
- 看起来像密钥的文件（`.env` 等）原地不动。
- 拿不准的文件默认不勾选。

## 识别与分发

- 默认关闭，要在设置的「识别」「分发」里自己打开。
- 打开识别后，文件正文会经本机 OpenClaw 发给云端模型。
- 请为识别单独建一个不带发送工具的代理，不要用 main。
- 识别结果和要发的消息都先放进「待分发」，等你确认。
- 第一次发给一个新收件人，只能先演练。
- 不会自动发送；真正发出后不能撤销。

## 自己构建

需要 Command Line Tools（Swift 6.3），不需要 Xcode。

```bash
swift test
./scripts/make_app.sh
open "dist/素材整理器.app"
```

第一次打开被系统拦住时，在访达里按住 Control 点「打开」。扫描桌面或下载前，到「系统设置 → 隐私与安全性 → 文件与文件夹」允许「素材整理器」。
